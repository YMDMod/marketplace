### Возможности

- Установка аддонов из [каталога](https://github.com/YMDMod/catalog) в одно действие, включая необходимые
  зависимости
- Проверка новых версий аддонов и самого мода при запуске клиента и далее каждые несколько часов
- Обновление мода по кнопке

Проверку обновлений можно отключить в настройках аддона на странице мода.
