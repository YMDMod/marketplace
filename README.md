### Возможности

- Аддоны из [каталога](https://github.com/YMDMod/catalog) ставятся одной кнопкой, вместе с нужными им
  зависимостями
- При запуске клиента и потом раз в несколько часов проверяет новые версии аддонов и самого мода
- Обновляет мод по кнопке.

Проверку обновлений можно выключить в настройках аддона на странице мода.
